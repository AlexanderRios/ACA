# Ferretería El Tornillo 🔩

Sitio web estático (*one-page*) moderno y responsive desarrollado para el negocio local **Ferretería El Tornillo**.

## 📌 Información del Negocio
- **Ubicación:** Calle 10 #23-45, barrio Los Pinos
- **Horario:** Lunes a sábado, 8:00 a.m. a 6:00 p.m.
- **Productos:** Herramientas, pintura, tornillería y material eléctrico.

---

## 📂 Estructura del Proyecto

```text
ferreteria-el-tornillo/
├── index.html          # Estructura principal y contenido
├── css/
│   └── estilos.css     # Estilos modernos y diseño responsive
└── js/
    └── contacto.js     # Lógica interactiva y validación del formulario
```

---

## 🚀 Características
- **100% Vanilla:** Construido exclusivamente con HTML5 semántico, CSS3 moderno y JavaScript puro (sin frameworks ni dependencias pesadas).
- **Diseño Responsive:** Totalmente optimizado para computadores de escritorio, tablets y teléfonos móviles.
- **Validación en Cliente:** El formulario de contacto valida que el campo de nombre tenga al menos 2 caracteres antes de permitir el envío, mostrando alertas visuales de advertencia y confirmación de éxito.
- **Secciones:**
  1. **Inicio (Hero):** Presentación del negocio, eslogan, horario destacado y datos de ubicación.
  2. **Servicios y Productos:** 4 tarjetas interactivas (*Herramientas*, *Pintura*, *Tornillería*, *Material Eléctrico*).
  3. **Contacto y Ubicación:** Información de atención y formulario interactivo.
